把数据铺开 —— CarPlay 上能做到多密

Dashboard 的目标是单位面积信息量。CarPlay Driving Task 的天花板由一件事决定： app 唯一能控制的像素，是模板允许的那几张图片。其余全归 iOS。 所以「铺开」这件事只有一条路 —— Grid 八格，每格塞一张自绘的密集面板。 数值走项目自带 DemoSession.generateSample()，阈值取自 src/analysis/bands.ts。

格子图片的尺寸上限是运行时属性 CPGridTemplate.maximumGridButtonImageSize， Apple 未公开固定值，随车机 scale（2x / 3x）变化 —— 所以下面把 tile 尺寸做成可切换的， 别拿一个猜出来的数当结论。 另一条已知坑：iOS 26 之前 Grid 有布局 bug，4–6 个按钮会挤成一行而不是网格，iOS 26 beta 6 才修。
